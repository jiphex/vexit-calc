# UKRI/UK Civil Service Voluntary Exit Calculator

A simple, single-page web application to calculate payments under the UK Civil Service Voluntary Exit Scheme, targeted at UKRI staff.

## Usage

### View Online

Visit the GitHub Pages site: <https://jiphex.github.io/vexit-calc/>

### Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/jiphex/vexit-calc.git
   cd vexit-calc
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Build TypeScript:
   ```bash
   npm run build
   ```

4. Open `index.html` in your browser or serve it:
   ```bash
   npm run serve
   ```
   Then visit `http://localhost:8000`

## Development

To watch for TypeScript changes during development:
```bash
npm run watch
```

## Important Notes

- This calculator provides **estimates only**
- Actual payments depend on your specific department's terms and conditions
- Different departments may have different calculation methods
- The ex-gratia element is often discretionary
- Always consult your HR department for official calculations
- Tax implications are not included in these calculations
